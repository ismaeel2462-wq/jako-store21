# JAKO STORE

متجر رقمي عربي مستقل للألعاب والتطبيقات والبطاقات الرقمية، يعمل بواجهة RTL داكنة وبرتقالية ومتصل بمشروع Supabase المخصص للمتجر.

## الصفحات

- `index.html`: الصفحة الرئيسية وباقي وظائف المتجر.
- `games.html`: مدخل مباشر إلى صفحة الألعاب.
- `applications.html`: مدخل مباشر إلى صفحة التطبيقات.

صفحتا الألعاب والتطبيقات تعرضان المنتجات النشطة من قاعدة البيانات نفسها. أضيف كتالوج تأسيسي يضم 6 ألعاب و6 تطبيقات. لم تتم إضافة أسعار افتراضية أو باقات وهمية؛ يجب اعتماد الباقات والأسعار الحقيقية من لوحة الإدارة قبل استقبال الطلبات.

## قاعدة البيانات

مشروع Supabase: `zfqhfrxvpbnzzrixjaxf`. يحتوي المخطط الأساسي على ملفات المستخدمين، الأدوار، التصنيفات، المنتجات، الباقات والمخزون، وسائل الدفع، البنرات، الإعدادات والطلبات. جميع الجداول العامة مفعّل عليها RLS.

## إعداد وتشغيل

1. افتح `index.html` من خادم محلي أو بعد نشره على GitHub Pages.
2. تحقق من عنوان Supabase ومفتاح `publishable` داخل `index.html`.
3. اضبط Authentication URL Configuration في Supabase على رابط الموقع المنشور.
4. أنشئ حساب الإدارة باستخدام البريد المعيّن في دالة تسجيل المستخدم ثم سجّل الدخول.
5. من لوحة الإدارة، أضف الباقات والأسعار الفعلية، وبيانات طرق الدفع، ثم فعّلها.

## النشر

راجع `DEPLOYMENT.md`. لم يُفعّل GitHub Pages أو يُرفع هذا الإصدار إلى GitHub بعد بسبب رفض تكامل GitHub لعمليات الكتابة بصلاحية 403.
