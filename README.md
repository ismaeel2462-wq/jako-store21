# JAKO STORE

متجر رقمي عربي للألعاب والتطبيقات والبطاقات الرقمية، بواجهة RTL وتصميم داكن وبرتقالي. الواجهة الرئيسية موجودة في `index.html` وتستخدم Supabase للمصادقة وبيانات المنتجات والطلبات والإعدادات.

## ملفات الواجهة

- `index.html`: التطبيق الرئيسي وواجهة المتجر ولوحة الإدارة.
- `games.html`: مدخل مباشر إلى عرض الألعاب.
- `applications.html`: مدخل مباشر إلى عرض التطبيقات.
- `store-assets/`: أصول المتجر، ومنها صورة QR لشام كاش.

## البنية الخلفية

مشروع Supabase المرجعي: `zfqhfrxvpbnzzrixjaxf`.

- مخطط `public` يحتوي بيانات المستخدمين والأدوار والمنتجات والباقات ووسائل الدفع والإعدادات والطلبات.
- جداول المورّد التأسيسية: `suppliers` و`supplier_variant_mappings` و`supplier_fulfillments`.
- جداول المورّد محمية بـ RLS، ولا تمنح صلاحيات مباشرة إلى `anon` أو `authenticated`. الإدارة الخلفية تكون عبر خدمة موثوقة فقط.
- لا تحفظ مفاتيح API أو كلمات المرور أو مفاتيح Supabase السرية في المستودع أو في جداول بيانات المورّد.

## دوال Supabase

مصادر الدوال النشطة وقت المراجعة في 2026-11-20 محفوظة في `supabase/functions/`:

- `store-web-analytics`: قراءة إحصائيات Cloudflare Web Analytics للوحة الإدارة. يتطلب جلسة مستخدم صالحة ودور `admin`.
- `refresh-syp-market-rate`: تحديث سعر الصرف من مصدر السوق مع التحقق من حداثة البيانات والتغير الكبير قبل تطبيق السعر.

راجع `supabase/functions/README.md` لمتطلبات الأسرار وملاحظات النشر. حفظ المصدر في Git لا ينشر الدالة تلقائياً.

## تكامل المورّد

تم تجهيز بنية قاعدة البيانات وربط المورّدين بالباقات وتتبع تنفيذ الطلبات مع مفتاح منع التكرار (`idempotency_key`). لا يوجد مورّد حقيقي مربوط حالياً، ولا تُرسل طلبات المتجر تلقائياً إلى طرف خارجي. لا تفعّل الإرسال الآلي قبل استلام وثائق API الحقيقية وبيانات sandbox واختبارها.

## التشغيل المحلي

1. افتح المشروع من خلال خادم محلي مثل VS Code Live Server.
2. تأكد من أن عنوان Supabase ومفتاح `publishable` في الواجهة هما بيانات المشروع الصحيحين.
3. اضبط Authentication URL Configuration في Supabase على نطاق الموقع الفعلي وعناوين إعادة التوجيه اللازمة.
4. سجّل الدخول بحساب الإدارة لإدارة المنتجات والباقات ووسائل الدفع.
5. لا تضع أي `service_role` أو `secret key` في ملفات HTML أو JavaScript التي تصل إلى المتصفح.

## النشر

راجع `DEPLOYMENT.md` قبل نشر نسخة جديدة. المستودع على GitHub لا يعني أن GitHub Pages مفعّل؛ يجب استخدام إعداد الاستضافة الفعلي للموقع. المفتاح `publishable` وحده مسموح في الواجهة، أما المفاتيح السرية فتُحفظ في Supabase Edge Function Secrets.

## حالة أرشيف الترحيلات

المجلد `supabase/migrations/` يحتوي حالياً على ملف تأسيس تكامل المورّد `20261120102254_supplier_integration_foundation.sql`. قاعدة الإنتاج تسجل ترحيلات أقدم أيضاً، لكن ملفات SQL الأصلية لهذه الترحيلات لم تكن موجودة في نسخة المستودع التي جرت مراجعتها. لا تعتبر المجلد حالياً أرشيفاً كاملاً لإعادة بناء قاعدة بيانات جديدة، ولا تنفّذ `supabase db reset` اعتماداً عليه. راجع `supabase/README.md` قبل أي استعادة أو إعداد مشروع جديد.
